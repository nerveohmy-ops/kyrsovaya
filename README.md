# GRINPICH NATION — учёт редких видов национального парка

Курсовой проект (C#, WinForms, .NET Framework 4.7.2, SQL Server LocalDB).

## Запуск
1. Откройте `kyrsovaya.slnx` в Visual Studio и нажмите F5.
2. При первом старте приложение само создаёт базу `NationalParkDB` (скрипт `kyrsovaya/Database/CreateDatabase.sql`).
   Тот же скрипт можно выполнить вручную в SSMS (сервер `(localdb)\MSSQLLocalDB`).
3. Если используется другой SQL Server, поправьте строку подключения в `App.config`.

## Структура
- `Data/` — работа с БД (репозитории)
- `Models/` — модель пользователя и сессия
- `Services/` — валидация, пароли, e-mail, оформление, экспорт CSV
- `Forms/` — формы приложения
- `Database/` — SQL-скрипт (8 таблиц, 15–20 записей в основных таблицах)
- `Images/` — фон и фотографии сотрудников

## Экскурсии и гиды
- Все авторизованные пользователи могут просматривать расписание, присоединяться к открытым экскурсиям и отменять свою запись.
- Гид может просматривать список записавшихся участников на экскурсиях, которые он ведёт.
- Научные сотрудники и администраторы могут создавать, редактировать, открывать и закрывать экскурсии, назначать гидов на экскурсии и переводить пользователей в роль «Гид».
